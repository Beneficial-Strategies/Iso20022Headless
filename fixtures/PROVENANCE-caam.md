## Business rules
There are none. Every one of the 145 new scopes (129 new types, 16 messages) was looked up for constraints and none has one; searches for
constraints by name (`ATM`, `Cassette`, `ATMCommand`) find nothing either. The rule counts of the library are unchanged (320).

## What these messages needed
- **Amounts with an implied currency** (`ImpliedCurrencyAndAmount`): no currency attribute on the wire, so the generator emits a plain decimal (18 digits, 5 fractional, at least 0) instead of `{ Ccy, Value }`.
- **`CurrencyAndAmount`** is checked against the code set `CurrencyCode` (three uppercase letters).
- **Alternation in text patterns** (`Max10DateText`): the pattern describer now describes `A|B|C` ("…; or …"). The spec's own wording of that type says "YY-MM, YYYY-MM or YYYY-MM-DD" and its second alternative is `[0-9]{2}-[0-9]{2}`; the pattern is kept as published.
- **Binary** values stay text (base64) with the published maximum length, as in pain.001.

## Known limits
- Spanish text is machine-drafted ("machine translated"). The terms for ATM (kept as the token "ATM", which the lint requires), cassette (cartucho) and acquirer (adquirente) were chosen here and are not in the glossary yet.
