ISO 20022 headless demos

A schema-driven data-entry form for the ISO 20022 pain.001.001.13 (customer credit transfer initiation) message, with live XML or ISO 20022 JSON output. The library renders nothing: every pixel on these pages is the demo's own markup.

With the TanStack Form hook

Form state comes from our React hook, built on TanStack Form. Validation is the generated Zod schema.

Things to try

  • Open Display (top right): language (English or Español), theme, text size, density, output format (XML or JSON), and the form skin.
  • Pick another part of the message with the Type field, such as a postal address or a whole payment instruction.
  • Click the i next to a label for the ISO 20022 definition; choose a code to see what it means.
  • Leave a required field empty, or break a business rule, and watch the validation and the rules panel respond.

Settings are kept in the page address, so a link reproduces your view. Nothing you type leaves your browser: these are static pages with no server.

Definitions and code lists come from the ISO 20022 repository. The Spanish text is machine-translated and marked as not yet reviewed. Source and documentation: github.com/Beneficial-Strategies/Iso20022Headless.
